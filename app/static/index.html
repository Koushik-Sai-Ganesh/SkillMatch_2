INTERPRETATION
01
Check imbalance

Attrition labels may be imbalanced; accuracy alone can hide poor recall for the smaller class.

02
Compare segments carefully

Department and role counts are descriptive. Compare rates as well as counts before interpreting patterns.

03
Look for data quality issues

Missing values, rare categories, and extreme values can influence preprocessing and model behaviour.

04
Remember the limits

This dataset is fictionalised/educational and does not map employee records to geography, so no map is meaningful here.

M1 → M6 · ENGINEERING MAP

Inside the ML lifecycle.

Follow the path from raw data to production monitoring, and find the code responsible for each stage.

↻
M1
Data ingestion & system entry point

src/data_ingestion.py loads raw CSV, checks quality, and writes the cleaned dataset. app/serve.py exposes the service.

M2
Feature engineering & linear models

src/feature_engineering.py prepares categorical and numeric features; training compares ridge-regularised logistic regression.

M3
Tree-based models

src/train.py fits XGBoost and calculates feature importance for the top encoded features.

M4
Unsupervised learning

K-means builds a risk-segment feature that is added to the supervised pipeline. It is a feature-engineering demo, not a standalone employee ranking.

M5
Evaluation & calibration

Stratified splits, 5-fold CV, precision, recall, F1, ROC-AUC and confusion matrices are produced during training.

M6
Packaging, serving & monitoring

models/skillmatch_model.joblib bundles the model artifact; FastAPI logs prediction latency and inputs; src/monitor.py checks a simple drift signal.

Run the system locally

From the project root folder

pip install -r requirements.txt

python src/train.py

cd app then uvicorn serve:app --reload --port 8000

Open http://localhost:8000 for the dashboard and http://localhost:8000/docs for interactive API documentation.

ABOUT THE PROJECT

SkillMatch / workforce analytics.

A teaching-oriented machine learning system for employee attrition risk, built around the ML lifecycle rather than a single notebook.

SM

Project objective

Demonstrate a working ML product: data ingestion, engineered features, supervised models, unsupervised segments, evaluation, model packaging, API inference, and basic monitoring.

Dataset

IBM HR Analytics Employee Attrition & Performance dataset, commonly distributed on Kaggle. It is a historical educational dataset and should not be treated as a representative or fair basis for real workforce decisions.
